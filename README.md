# Briarhold

A voxel dungeon game that runs in the browser. Play it at **https://vegou.github.io/briarhold/**.

This repository holds only the built game (`index.html`, a single page). It is rebuilt from the game's source and replaced here when the game changes.

Playing together (pause menu → **Play together**): the host gets an 8-character code, friends type it in. The games connect directly where they can, and otherwise through a relay over public message servers; everything between them is encrypted with the room code.
